# 🎨 Editor de Imágenes Web con React y Vite

Aplicación web interactiva desarrollada con **React y Vite**, diseñada para cargar, manipular y aplicar efectos visuales a imágenes en tiempo real utilizando las propiedades de **Filtros CSS** y hooks de React (`useState`, `useEffect`).

## 🚀 Demo en Vivo
- **Prueba la aplicación aquí:** [https://effervescent-tartufo-18a82c.netlify.app/](https://effervescent-tartufo-18a82c.netlify.app/)

---

## 🛠️ Tecnologías y Herramientas Utilizadas

- **React.js (con Vite)** — Framework y empaquetador de alto rendimiento.
- **JavaScript (ES6+)** — Lógica de programación y manipulación de estados.
- **Filtros CSS** — Aplicación dinámica de efectos visuales sobre imágenes.
- **Hooks de React** — Uso de `useState` para gestión de estados locales e interfaz, y `useEffect` para efectos secundarios.
- **HTML5 & CSS3** — Estructura y diseño responsivo.
- **Git & GitHub** — Control de versiones.

---

## ✨ Características Principales

- 🖼️ **Carga de imágenes:** Sube cualquier imagen desde tu dispositivo local al instante.
- 🎛️ **Filtros en tiempo real:** Modifica propiedades visuales aplicando filtros de CSS dinámicos (Brillo, Contraste, Saturación, Escala de grises, Sepia, etc.).
- ⚡ **Rendimiento optimizado:** Interfaz fluida y rápida gracias a Vite.
